## 🌟 Overview & Value Proposition

**PuretyFarm** is a direct-to-consumer milk subscription service delivering 100% pure, raw, chilled A2 Gir cow milk to households across Raipur, Chhattisgarh.

- **100% Indigenous Desi Gir Cows**: Naturally rich in the A2 beta-casein protein, easier to digest, and sourced from ethically reared cows free-range grazing in organic pastures.
- **Milked at Dawn, Delivered by 10:00 AM**: Milked at 4:30 AM, immediately chilled at 4°C, and dispatched straight to customer doorsteps in morning slots (delivered before 10:00 AM).
- **Eco-Friendly Sanitized Glass Bottles**: Plastic-free distribution in sterilized, temperature-preserving glass bottles collected and sanitized daily.
- **40+ Rigorous Quality Checks**: Zero preservatives, zero synthetic fats, zero added water, and zero antibiotics or growth hormones. FSSAI licensed.
- **Zero-Risk 7-Day Starter Experience**: 100% money-back guarantee with cancel-anytime flexibility and no long-term commitment.

## 🛠️ Technology Stack

- **Framework**: [Next.js](https://nextjs.org/) 16 (App Router, React 19, TypeScript)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) v4 with `@tailwindcss/postcss`
- **Typography**: Next.js Google Fonts (`Playfair Display` for serif luxury headings, `Plus Jakarta Sans` for clean UI body text)
- **Animations**: [GSAP](https://greensock.com/gsap/) (GreenSock Animation Platform) 3.15 + [ScrollTrigger](https://greensock.com/scrolltrigger/) + `@gsap/react`
  - Hero staggered entrance and floating parallax ambient blobs
  - Stepped SVG timeline connector drawing
  - 3D phone mockup entrance with perspective tilt
  - Accordion height transitions and scroll reveal triggers
- **Icons & Graphics**: Native SVGs + Next.js `<Image />` optimization

## 🚀 Getting Started & Local Development

### 1. Prerequisites
- **Node.js**: v18.18.0 or later (v20+ recommended)
- **Package Manager**: `npm`, `pnpm`, or `yarn`

### 2. Installation
Clone the repository and install project dependencies:

```bash
git clone https://github.com/SevenX-Labs/puretyfarm-customer-webapp.git
cd puretyfarm-customer-webapp
npm install
```

### 3. Development Server
Start the local Next.js development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to inspect the application.

### 4. Production Build & Linting
Validate TypeScript types and compile the optimized production bundle:

```bash
# Run ESLint validation
npm run lint

# Compile production bundle
npm run build

# Start production server
npm run start
```

## 📈 SEO, Performance & Accessibility

- **Structured Data (JSON-LD)**: Built-in `Schema.org` schemas for `LocalBusiness` (address, geo-coordinates `21.2514, 81.6296`, opening hours) and `Product` (`AggregateOffer` with pricing ₹45 – ₹150).
- **Social Sharing**: Complete OpenGraph (`og:image`, `og:title`, `og:description`) and Twitter Card metadata.
- **Accessibility**: Semantic HTML5 elements (`<nav>`, `<main>`, `<section>`, `<footer>`), ARIA attributes on accordions (`aria-expanded`), search inputs, and mobile dialogs.
- **Performance**:
  - Image optimization via `next/image` with WebP compression.
  - Dynamic client-side component code-splitting with skeleton placeholders for non-hero sections.
  - Zero layout shift (CLS prevention) on hero elements and buttons.
